# 高校活动报账材料整理技能

这是一个面向支持技能和本地文件操作的 AI 助手的工作流程，帮助整理高校及学生组织活动的方案、预算决算和报销凭证。它以材料原件和适用的报销指引为依据，区分发票金额、付款、退款与拟报金额；具体报销资格和金额仍须由财务审核确定。

## 复制给 AI：安装并使用

在具有本地文件访问权限、支持技能的 Codex 或其他 AI 助手中，将下列提示词发给助手，并替换方括号中的内容：

```text
请安装并使用 activity-reimbursement 技能，仓库地址为：
https://github.com/Tau0509/activity-reimbursement-skill

请先检查仓库结构和 SKILL.md；该仓库的 SKILL.md 在根目录。优先使用当前宿主支持的技能安装工具，例如 Codex 的 skill-installer；若该工具不能安装根目录技能，请按宿主文档将完整技能目录安装到受支持的位置。保留 SKILL.md、references、scripts 的相对路径。若目标已存在，请先检查并保留已有本地改动，不要覆盖。

安装后告知我如何使技能生效；如需重启或开启新会话，请明确说明。技能可用后，请依据 [报销指引路径] 整理 [材料目录]，将成果保存到 [输出目录]。
```

技能需要宿主支持读取技能说明、访问相关文件并执行必要的文件操作。普通网页聊天中的 AI 不一定能安装技能或直接操作本地文件。Codex 技能目录与安装方式可参考[官方技能文档](https://learn.chatgpt.com/docs/build-skills)。

也可在终端中手动安装到 Codex 用户技能目录：

```bash
mkdir -p ~/.agents/skills
git clone https://github.com/Tau0509/activity-reimbursement-skill.git ~/.agents/skills/activity-reimbursement
```

如果目标目录已存在，`git clone` 不会覆盖它。请先检查其中的本地改动，再决定如何更新；不要删除或覆盖已有文件。安装后若当前会话未发现技能，可重启 Codex 或开启新会话。

## 复制给 AI：完整整理

```text
请使用 activity-reimbursement 技能，依据 [报销指引路径] 整理 [材料目录]。

请核对发票、订单、付款和退款，区分票面金额与实际支付金额，标明差额、证据缺失和待核事项；依据现有材料润色策划方案，制作可编辑的决算 Excel，并将真实工作簿截图及相关凭证汇编为 Word。按策划书、决算表、发票、订单记录、支付记录的顺序整理。

请保留原件，将成果输出至 [输出目录]。不补造数据、凭证、事前审批或财务结论；报销口径以适用规定及财务审核为准。
```

```text

请保留原文件，建立阅读说明和原文件名与新文件名对照，检查文件覆盖情况和压缩包完整性。仅纳入本次报销相关文件，不要顺带打包报名表、学生名单或无关个人信息。
```

## 功能与适用范围

- 对照发票、订单、付款、已核实退款和来源，标出差额、疑似重复及资料缺失。
- 根据现有事实润色中文方案，区分原预算、已批准预算、事后补充估算与实际决算。
- 在具备相应工具的环境中制作或更新可编辑 Excel、整理 Word 汇编，并检查截图和打印版式。
- 按明确文件映射复制、命名和打包材料，生成文件清单及哈希校验信息。
- 附有华中科技大学青马学校报销指引摘要，使用时应结合实际适用的最新指引；其他单位应采用其自身要求。

具体操作范围以用户本次要求为准。技能不办理财务系统提单，不验证票据真伪，也不代替财务部门认定可报销金额。

## 脚本与运行环境

仓库中的两个辅助脚本需要 **Python 3.11 或更高版本**，只使用 Python 标准库。它们不是完整的 Word 或 Excel 生成器；制作、重算和渲染文档需要宿主提供相应的文档／表格工具、渲染能力及适用字体。公文模板和其他技能可按宿主环境使用，缺少时应说明实际采用的方式。

在仓库根目录运行示例：

```bash
python3 scripts/check_ledger.py examples/ledger.example.json
python3 scripts/package_packet.py examples/packet.example.json --output-dir demo-output
```

`check_ledger.py` 根据 JSON 中记录的金额核对汇总、退款、差额和部分来源字段，结果默认输出到终端，可使用 `--output` 保存。退出码为 0 不代表凭证齐备或财务审核通过。`package_packet.py` 按 JSON 清单中显式列出的文件复制并打包，源文件相对路径以清单所在目录为基准；可先加 `--dry-run` 检查计划。打包脚本拒绝覆盖同名输出目录或 ZIP，重复运行前请更换输出目录或包名。示例数据仅用于演示。

字段和清单格式见 [核账与归档数据](references/data-and-packaging.md)，方案及排版说明见 [方案与汇编制作](references/writing-and-layout.md)。
